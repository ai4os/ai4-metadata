Third party assets
------------------

The following assets are copies of the official `MLDCAT-AP
<https://semiceu.github.io/MLDCAT-AP/>`_ release files by `SEMIC
<https://interoperable-europe.ec.europa.eu/collection/semic-support-centre>`_,
taken from the `SEMICeu/MLDCAT-AP <https://github.com/SEMICeu/MLDCAT-AP>`_
repository. They are bundled so that the RDF output and the SHACL validation work
without network access.

* `MLDCAT-AP 2.1.0 JSON-LD context <_static/json-ld/semic/mldcat-ap-2.1.0.jsonld>`_,
  a copy of ``releases/2.1.0/context/mldcat-ap.jsonld``, imported by the AI4
  MLDCAT-AP context above.
* `MLDCAT-AP 2.1.0 SHACL shapes <_static/shacl/semic/mldcat-ap-2.1.0-SHACL.ttl>`_,
  a copy of ``releases/2.1.0/shacl/mldcat-ap-SHACL.ttl``, used by the optional
  SHACL validation.
