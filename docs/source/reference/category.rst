.. rdf-vocabulary:: Category
   :source: assets/rdf/ai4eosc-category.ttl
   :static: ../_static/rdf/ai4eosc-category.ttl
   :format: turtle

   Platform categories of a module, used in the ``categories`` field of the AI4
   metadata. They describe how a module can be used in the platform, for example
   whether it can be trained or it provides a pre-trained model.

   In MLDCAT-AP, categories are mapped to ``dct:type``.
