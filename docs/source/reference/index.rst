AI4 Metadata reference
======================

This section describes the controlled vocabularies used by the AI4 metadata. Each
vocabulary defines the concepts for one of the metadata fields:

* :doc:`category`: the ``categories`` field.
* :doc:`tasktype`: the ``tasks`` field.
* :doc:`library`: the ``libraries`` field.

Every entry has a stable URI under ``http://w3id.org/ai4os/vocabulary/``. These URIs
are used when the metadata is mapped to linked data profiles, such as MLDCAT-AP (see
:doc:`../profiles`). Each vocabulary is also available as an RDF (Turtle) file.
